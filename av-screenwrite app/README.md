# AV-сценарий

Бесплатный офлайн-редактор двухколоночных сценариев (слева видео, справа звук) с автоподсчётом хронометража.
Без аккаунтов, без сети, без телеметрии. Интерфейс на русском, английском и польском.

**Версия 0.2.0.** Подробный план — в документе «План: десктопное приложение для AV-сценариев».

## Что умеет

- **Список проектов.** При запуске открывается экран «Проекты»: карточки с названием, автором, числом строк и слов, хронометражем и временем изменения. Создание, поиск, дублирование, удаление (с кнопкой «Вернуть»), импорт и экспорт файлов `.avs`.
- **Работа с одним проектом.** Проект сохраняется автоматически (через 0,7 с после правки, при уходе из окна и при закрытии) — кнопки «Сохранить» нет, есть индикатор «Сохранено».
- **Редактор.** Строки «Видео / Звук / Время», автоподсчёт времени по словам в колонке звука (`ceil(слова × 60 / темп)`, темп 40–400), ручное время, таймкоды, общий хронометраж, перетаскивание и перемещение строк, единая отмена/повтор.
- **Форматирование текста.** Жирный (`Ctrl+B`), курсив (`Ctrl+I`), подчёркнутый (`Ctrl+U`), зачёркнутый (`Ctrl+Shift+X`), «убрать форматирование». Оформление сохраняется в проекте и попадает в PDF и Word. На подсчёт слов и время оно не влияет.
- **Экспорт.** PDF (A4/Letter, шапка таблицы на каждой странице, номера страниц) и настоящий `.docx` (редактируемая таблица, шрифт вшит в файл).
- **Оформление.** Тёплая «бумажная» тема: кремовый лист на столе, терракотовый акцент, заголовки шрифтом PT Serif, текст сценария шрифтом PT Mono (как в PDF и Word). Светлая и тёмная тема — по настройке Windows.
- **Языки.** Русский, English, Polski; переключатель на экране «Проекты» (справа вверху), выбор запоминается. Переводятся интерфейс, подписи в PDF/Word, даты и склонения («1 строка, 2 строки, 5 строк» / "1 row, 2 rows" / „1 wiersz, 2 wiersze, 5 wierszy”).

## Где лежат данные

Проекты — обычные файлы `<id>.avs` в папке данных приложения:

```
%APPDATA%\ru.av-scenariy.app\projects\
```

Рядом с каждым проектом лежит `<id>.avs.bak` — предыдущая версия; запись атомарная (временный файл → переименование).
Удалённые проекты переносятся в подпапку `.trash` и остаются там, пока вы не очистите её вручную.
Для переноса на другой компьютер используйте «Сохранить копию в файл .avs» на карточке проекта или кнопку «Файл .avs» в редакторе, а на другом компьютере — «Открыть файл .avs…».

## Формат .avs

UTF-8 JSON с полями `format` и `version`. Меняется только через миграции.

| Версия | Что в ней |
| --- | --- |
| 1 | только текст (прототип и первые сборки) |
| 2 | добавлены `videoFmt` / `audioFmt` — оформление текста: список диапазонов `{from, to, b?, i?, u?, s?}` |

Файлы версии 1 и файлы из HTML-прототипа читаются без изменений; приложение всегда пишет версию 2.
Неизвестные поля сохраняются и пишутся обратно. Файл более новой версии не открывается (и не импортируется), чтобы ничего не потерять; повреждённый файл не перезаписывается и показывается в списке с пометкой.

## Быстрый старт для разработки

Нужен Node.js 20.19+ (проверено на 24):

```bash
npm install
npm run dev        # интерфейс в браузере: http://localhost:1420 (проекты — в localStorage браузера)
npm test           # юнит-тесты (Vitest)
npm run build      # проверка типов + сборка интерфейса
```

Для настольной версии нужны [Rust](https://rustup.rs) и (на Windows) «Microsoft C++ Build Tools»:

```bash
npm run tauri dev      # окно приложения с горячей перезагрузкой
npm run tauri build    # готовые exe и установщик (см. ниже)
```

> В Windows PowerShell команда `npm` может быть заблокирована политикой выполнения скриптов. Используйте `npm.cmd run tauri dev`.

## Готовые файлы

После `npm run tauri build` (их копию кладём в папку `release\`):

| Файл | Что это |
| --- | --- |
| `release\AV-сценарий.exe` | одиночный exe: запускается двойным щелчком, ничего не устанавливает, интерфейс вшит внутрь |
| `release\AV-сценарий_0.2.0_x64-setup.exe` | установщик (NSIS) для текущего пользователя, права администратора не нужны |

Для работы нужен Microsoft Edge WebView2 Runtime — в Windows 10/11 он уже есть. Файлы без подписи кода, поэтому Windows SmartScreen при первом запуске может показать предупреждение: «Подробнее» → «Выполнить в любом случае».

## Устройство

```
src/core/      ядро без DOM: модель документа, хронометраж, форматирование (richtext), команды, стек отмены, формат .avs
src/ui/        editor.ts (строки и ввод), richdom.ts (DOM ↔ модель), home.ts (список проектов), dialogs.ts
src/export/    model.ts (что попадёт в файл), pdf.ts, docx.ts, wrap.ts, font.ts; загружаются лениво
src/i18n/      ru.json, en.json, pl.json + index.ts (выбор языка, склонения через Intl.PluralRules)
src/library.ts проекты: Tauri-команды (файлы) или localStorage (в браузере)
src/platform.ts диалоги и файлы: Tauri, а в браузере — запасной вариант
src-tauri/     оболочка: окно, CSP, права, Rust-команды (атомарная запись, библиотека проектов)
assets/fonts/  PTMono-Regular.ttf (для PDF и Word) и лицензия OFL 1.1
tests/         Vitest: ядро, формат, форматирование, экспорт (в т. ч. рендер через pdfium), DOM-разбор
```

Новый язык: добавить `src/i18n/<код>.json` с теми же ключами, записать его в `src/i18n/index.ts` (`DICTS`, `LANGUAGES`). Тест проверяет, что во всех словарях одинаковые ключи и подстановки.

## Безопасность и приватность

CSP без `unsafe-eval` и без внешних адресов (`connect-src` только IPC Tauri); в правах Tauri — только диалоги файлов и управление окном; HTTP-плагина, shell и fs-плагина нет.
Rust-команды читают и пишут только `.avs` / `.json` (импорт и экспорт) и файлы `<id>.avs` внутри папки проектов; идентификатор проекта — только `[a-z0-9]`, выйти за пределы папки нельзя. Приложение не делает сетевых запросов.

## Горячие клавиши

Везде: `Ctrl+N` — новый проект.
Список проектов: `Ctrl+O` — открыть файл `.avs`.
Редактор: `Ctrl+O` — к списку проектов · `Ctrl+S` — сохранить сейчас · `Ctrl+Shift+S` — копия в файл `.avs` · `Ctrl+P` / `Ctrl+Shift+E` — PDF / Word ·
`Ctrl+Z`, `Ctrl+Shift+Z`, `Ctrl+Y` — отмена и повтор · `Ctrl+Enter` — новая строка ниже · `Alt+↑/↓` — переместить строку · `Ctrl+D` — дублировать ·
`Ctrl+Shift+Backspace` — удалить строку · `Ctrl+Shift+K` — поменять колонки · `Ctrl+B/I/U`, `Ctrl+Shift+X` — форматирование · `Ctrl+=` / `Ctrl+-` / `Ctrl+0` — масштаб текста.
На macOS вместо `Ctrl` — `Cmd`. Клавиши определяются по физической клавише и работают в любой раскладке.
